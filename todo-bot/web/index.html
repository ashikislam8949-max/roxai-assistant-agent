        Useful starting points

        For investment, start with MISA/Invest Saudi; for commercial services, use the Ministry of Commerce; for municipal permits and requests, use Balady. Residents should use Absher for official resident services. For identity checks, follow the official gateway’s Nafath approval flow yourself. Qiwa handles employment services; Najiz handles justice services.

        Identity verification is not automated by ToDO BoT or GitHub. A direct Nafath or government API connection would require the relevant authority’s official API, approval, security review, and credentials; this app does not collect government identity data or claim such integration.

        Hosting at 2do.net: GitHub Pages can publish this static web app on a custom domain you own after you configure the Pages site and DNS. GitHub Pages cannot run the backend, securely store identity credentials, or supply government APIs. Keep app/API secrets out of the repository. See GitHub’s custom-domain setup guide.
